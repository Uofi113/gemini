## 🇬🇧 English

> A native Gemini client for a device that was already outdated when the App Store still called apps "programs."

**G6mini** is a fully native Objective-C client for Google Gemini, hand-built for iOS 6 — no Storyboards, no Auto Layout, no modern conveniences. Every pixel is a `CGRectMake`. Every gradient is drawn by hand. It runs on an iPhone 4 and an iPad 2, and it was built specifically to feel *native* to that era, not like a modern app squeezed onto old glass.

### ✨ What it actually does

**Chat**
- Real-time streaming replies (SSE) with an animated "typing…" bubble while Gemini thinks
- Regenerate the last answer, or retry instantly if the connection drops mid-request
- Long-press any message to copy it
- Photo attachments and voice messages, recorded and sent right from the chat
- Expandable code blocks with basic syntax coloring
- A running token-estimate indicator so you don't blindly overflow the model's context
- Chat titles generated by Gemini itself after your first message — not just a truncated substring

**Make it yours**
- Multiple named **personal context presets** — switch your Gemini "personality" per conversation instead of editing one static field
- RU / EN toggle that actually changes what language Gemini replies in, not just the UI
- Three text sizes, dark and light themes, pinned chats, optional per-chat avatars
- Two chat list styles: the plain classic rows, or a grouped card layout with shadows and a top-gloss highlight
- Tab bar or a classic bottom toolbar — pick your navigation, switched live, no restart

**Built for the hardware, not despite it**
- Full `UISplitViewController` master-detail layout on iPad — this isn't a stretched iPhone app
- A reachability check before every send, so a dead connection fails instantly instead of after a 30-second timeout
- Careful iOS 6-era memory hygiene: delegates are nil'd out in `dealloc`, `CALayer` mutation during cell reuse won't crash the app, `UIActionSheet`/`UIPopoverController` are positioned correctly on iPad

### 🛠 Building it

The project builds with **[Theos](https://theos.dev)** targeting `iphone:clang:latest:6.0`. Every push to `main` triggers a GitHub Actions build that spits out a ready `.deb`.

```bash
make package FINALPACKAGE=1
```

The resulting package installs like any other Theos application package on a jailbroken iOS device.

## 🇷🇺 Русский

> Нативный клиент Gemini для устройства, которое устарело ещё тогда, когда App Store называл приложения "программами".

**G6mini** — это полностью нативный Objective-C клиент для Google Gemini, написанный вручную под iOS 6: без Storyboard'ов, без Auto Layout, без современных удобств. Каждый пиксель — это `CGRectMake`. Каждый градиент нарисован руками. Приложение реально работает на iPhone 4 и iPad 2, и делалось так, чтобы ощущаться *родным* для этой эпохи, а не модным приложением, натянутым на старое стекло.

### ✨ Что реально умеет

**Чат**
- Ответы приходят потоково (SSE) в реальном времени, с анимированными точками "печатает…", пока Gemini думает
- Перегенерация последнего ответа и мгновенный повтор запроса, если связь оборвалась
- Долгий тап по сообщению — копирование текста
- Фото и голосовые сообщения прямо из чата
- Раскрывающиеся блоки кода с базовой подсветкой синтаксиса
- Счётчик примерного расхода токенов, чтобы не улететь в лимит контекста модели вслепую
- Название чата придумывает сама Gemini после первого сообщения — а не обрезанная подстрока, как раньше

**Под себя**
- Несколько именованных **пресетов личного контекста** — переключай "личность" Gemini под конкретный разговор, а не редактируй одно статичное поле
- Переключатель RU / EN реально меняет язык ответов Gemini, а не только интерфейс
- Три размера текста, тёмная и светлая темы, закреплённые чаты, аватарки чатов по желанию
- Два стиля списка чатов: классические строки или карточки с тенью и бликом сверху
- Таб-бар или классический тулбар снизу — переключается на лету, без перезапуска

**Сделано под железо, а не вопреки ему**
- Полноценный `UISplitViewController` на iPad — это не растянутое iPhone-приложение
- Проверка сети перед каждой отправкой: обрыв связи обрабатывается мгновенно, а не через 30 секунд ожидания
- Аккуратная работа с памятью в духе iOS 6: делегаты обнуляются в `dealloc`, мутация `CALayer` при переиспользовании ячеек не роняет приложение, `UIActionSheet`/`UIPopoverController` корректно позиционируются на iPad

### 🛠 Сборка

Проект собирается через **[Theos](https://theos.dev)** с таргетом `iphone:clang:latest:6.0`. Каждый пуш в `main` запускает сборку в GitHub Actions и выдаёт готовый `.deb`.

```bash
make package FINALPACKAGE=1
```

Собранный пакет устанавливается как любое другое Theos-приложение на джейлбрейк-устройстве.
