# G6mini (ранее GeminiApp) — Клиент Google Gemini для iOS 6.x

## О проекте
- **Что это:** Нативный клиент для нейросети Google Gemini, написанный специально для старых устройств на базе iOS 6.
- **Автор:** Uofist | https://t.me/iOS6Great
- **Язык:** Objective-C
- **Архитектура:** Классическая MVC без Storyboards и AutoLayout (только хардкод фреймов и `autoresizingMask`), сборка через Makefile (без Xcode, компилируется с помощью Theos/Make на GitHub Actions или локально).
- **Путь проекта локально:** `C:\Projects\geminiios6`
- **Гит-репозиторий:** `https://github.com/Uofi113/gemini` (ветка `main`)

## Важные правила работы (КРИТИЧНО ДЛЯ CLAUDE)
1. **ВСЕГДА делай `git push` и `git pull`**: Пользователь собирает проект через GitHub Actions (или на другой машине). Любые изменения кода нужно сразу пушить в `main`, иначе пользователь не сможет собрать новый билд.
2. **НИКАКИХ СТАНДАРТНЫХ КОММЕНТАРИЕВ В КОДЕ**: Пользователь строго запретил использовать обычные комментарии (чтобы защититься от копипаста). Каждая модификация должна идти без комментариев. **Единственное исключение** — самая первая строка каждого `.m` и `.h` файла ДОЛЖНА БЫТЬ строго: `// Uofist | https://t.me/iOS6Great`.
3. **НИКАКОГО AUTOLAYOUT**: iOS 6 не поддерживает современные `NSLayoutConstraint`. Вся верстка делается через `CGRectMake` и математику (в том числе ручной расчет ширины текста через `sizeWithFont:`).
4. **Безопасность iOS 6**: 
   - `UITextField.delegate` и `UITableView.delegate` в iOS 6 имеют тип `assign`, а не `weak`. Обязательно нужно обнулять делегаты в `- (void)dealloc` (`self.field.delegate = nil;`), иначе при закрытии окна (popViewController) приложение упадет из-за `EXC_BAD_ACCESS`.
   - Внимательно работай с `CALayer`: нельзя слепо удалять слои через `removeFromSuperlayer` из массивов `sublayers`, если там есть системные слои от `UILabel` или `UIImageView`.
   - `UIActionSheet` и `UIPopoverController` на iPad требуют обязательной привязки к координатам (`showFromRect:` / `UIPopoverArrowDirectionAny`).
5. **Внимание к кодировке файлов**: Проект использует кириллицу. Если меняешь файлы скриптами (например, Python), обязательно используй `encoding="utf-8"`, иначе кириллица сломается.

## Контекст и что уже сделано
- **Защита от воровства**: Код полностью очищен от стандартных комментариев. Во все файлы добавлена подпись `// Uofist | https://t.me/iOS6Great`. В фон добавлен водяной знак.
- **Интерфейс чата (ChatBubbleCell)**: Убраны аватарки пользователей в самом чате (оставлены только для списка чатов). Пузырьки сообщений переписаны так, чтобы они плотно облегали текст, а не растягивались на весь экран. На iPad стоит ограничение ширины пузыря (max 480).
- **Настройки (SettingsViewController)**: 
  - Верстка полностью переписана под iPad (элементы по центру шириной 400px).
  - Добавлена кнопка-инструкция "Где взять API ключ?", которая открывает безопасный `UIAlertView`, так как Safari на iOS 6 отваливается из-за новых SSL сертификатов Google.
  - Добавлен переключатель языка (RU / EN), который напрямую подкидывает `systemInstruction` в API Gemini, заставляя нейросеть отвечать на нужном языке.
- **Исправление крашей**: 
  - Исправлен фатальный краш iPad при открытии меню чата и поповера выбора фото.
  - Исправлен фатальный краш при возврате на экран `ChatListViewController` (мутация массива `CALayer` во время итерации).
  - Исправлены краши с делегатами при скрытии клавиатуры.

## Что нужно сделать дальше (Next Steps)
1. **Глобальная локализация (Полировка)**: Я начал переводить элементы UI на английский через макрос `L(@"Ру", @"En")`, зависящий от `AppLang` в `NSUserDefaults`. Местами (в алертах) остался хардкод русского языка. Нужно доперевести интерфейс.
2. **Баги рендеринга Markdown**: Gemini иногда выдает сложные маркдаун-таблицы или код. Парсер `ChatMessageParser` может нуждаться в доработке, чтобы текст на iOS 6 рендерился без "глюков" и зависаний интерфейса при скролле.
3. **Тестирование утечек памяти**: Из-за отсутствия ARC-слабых ссылок на iOS 6 в некоторых местах, стоит проверить код на циклические ссылки (retain cycles), особенно внутри блоков в `NSURLConnection` (заменить `self` на `__weak typeof(self)`).
4. **Отправка файлов**: Пока поддерживается только отправка картинок и голосовых. Можно рассмотреть добавление отправки документов.
